☁️ Setup Sinkronisasi Firebase (Gratis)

Dengan Firebase, data kamu tersimpan di cloud Google — bisa diakses dari HP maupun Mac secara real-time. Gratis selamanya untuk pemakaian personal.

Langkah 1

Buka console.firebase.google.com → login dengan akun Google → klik "Create a project" → beri nama budget-jess → klik Continue sampai selesai.

Langkah 2

Di sidebar kiri, klik Build → Realtime Database → Create Database. Pilih region Singapore → pilih "Start in test mode" → Enable.

Langkah 3

Kembali ke Project Overview → klik ikon </> (Web app) → beri nama app → klik Register. Akan muncul kode firebaseConfig = { ... } — copy semua teks itu.

Langkah 4

Paste kode config di bawah ini, lalu klik Hubungkan. Setelah terhubung, data otomatis sync ke semua device.

📱 Cara pakai di HP setelah terhubung

iPhone / iPad

Buka link Netlify di Safari → tap ikon Share → pilih "Add to Home Screen" → beri nama "Budget Jess" → Add. Sekarang ada icon di homescreen seperti app beneran.

Android

Buka link Netlify di Chrome → tap menu (titik tiga) → pilih "Add to Home screen" → Add.

Penting

Di HP, buka tab ☁️ Sync → paste config yang sama + kunci yang sama → Hubungkan. Setelah itu semua data langsung sync!
